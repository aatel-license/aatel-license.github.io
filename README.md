# AATEL License
![Alt  "aatel"](https://raw.githubusercontent.com/aatel-license/aatel-license.github.io/refs/heads/main/imgs/ipercubo_aatel.png)

**AATEL (Anti-AI Training Ethical License)** is an ethical license designed to protect the creative work of developers in the age of artificial intelligence.

> "Software is an act of generosity. Protecting it means protecting our creativity." ([dev.to](https://dev.to/mirko_perrone_9dbd3752227/why-aatel-was-created-a-pact-of-respect-for-software-4in6))

## 🌍 What is AATEL?

AATEL introduces a new model of licensing:

- ❌ It is not traditional open-source  
- ❌ It is not proprietary  
- ✅ It is an **ethical license**

It was created to ensure that software is used with respect, intention, and responsibility.

## ⚖️ The 3 Pillars

### 🧠 1. Respect for ingenuity
- It is forbidden to use the code to train AI systems without explicit consent

### ☮️ 2. Ethics and peace
- Prohibited use for:
  - Weapons
  - Military surveillance
  - Harmful technologies

### 🤝 3. Mutual sustainability
- Free usage for:
  - Individuals
  - Non-profits
  - Companies with revenue < €1M
- Larger companies must contribute financially ([dev.to](https://dev.to/mirko_perrone_9dbd3752227/why-aatel-was-created-a-pact-of-respect-for-software-4in6))
